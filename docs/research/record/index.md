## 科研的基本闭环

科研的本质，是围绕问题建立一个完整的认知与行动闭环：

> **发现问题 → 分析问题 → 解决问题**

其中，**归因能力**决定了我们能否穿透表面现象，识别问题背后的关键原因，并进一步找到真正值得研究的方向。

换句话说：

> **归因，是从具体问题中提炼研究方向的能力。**

## 领域认知（奠基论文）

> 高质量 venue 门控 → 关键词扩展 → 前后向引用追踪 → 共被引分析 → 阅读引用上下文 → 识别贡献继承关系。

| 名词 | 一句话解释 |
|---|---|
| Venue | 论文正式发表的会议或期刊。 |
| 高质量 venue 门控 | 先只保留 CCF-A/B 或高影响力期刊论文，排除低质量论文。 |
| 关键词扩展 | 从初始关键词出发，继续收集论文中出现的别名和相关术语，避免漏检。 |
| 后向引用追踪 | 查看一篇论文引用了哪些更早的论文，用来寻找它的理论和方法来源。 |
| 前向引用追踪 | 查看后来有哪些论文引用了这篇论文，用来判断它产生了什么后续影响。 |
| Snowballing | 从少量可靠论文出发，沿着前向和后向引用不断扩展论文集合。 |
| 共被引分析 | 如果两篇论文经常被其他论文同时引用，说明它们可能属于同一研究方向或知识基础。 |
| Small 1973 | Henry Small 在 1973 年提出共被引分析，用引用关系识别研究领域的知识结构。 |
| 阅读引用上下文 | 阅读论文在什么语境下引用另一篇论文，判断它是在介绍背景、比较方法，还是实际继承方法。 |
| 贡献继承关系 | 明确后续论文具体继承了早期论文的问题定义、方法、数据集、指标还是系统架构。 |
| Semantic Scholar | 一个学术论文搜索与引用分析平台，可以查询论文的元数据和引用关系。 |
| References | 当前论文参考文献列表中的早期论文，即“它引用了谁”。 |
| Citations | 后来引用当前论文的其他论文，即“谁引用了它”。 |
| 引用图 | 将论文视为节点、引用关系视为连线形成的网络。 |
| OpenAlex | 一个开放的学术数据库，提供论文、作者、venue、主题和引用关系数据。 |
| FWCI | 按论文所属领域、年份和类型校正引用量，用来更公平地比较新旧论文的影响力。 |


## 找 idea 阶段

> 读论文方式：只看「标题」 + 「摘要」
> 
> idea 必须解决「三个问题」

1. **为什么这是一个问题？**
2. **为什么现有方法解决不了？**
3. **为什么你的方法能够解决？**

### 1. 现有问题是什么？

不仅要描述当前存在的现象，还需要进一步说明：

> **为什么它构成了一个值得研究的问题？**

也就是说，需要明确问题带来的影响、研究价值以及解决这一问题的必要性。

### 2. 现有方法为什么不够好？

需要分析已有工作的能力边界与不足，包括：

* 哪些问题尚未被解决；
* 哪些假设限制了方法的适用范围；
* 哪些场景下现有方法会失效；
* 问题的根本原因是什么。

这一阶段的重点，不是简单指出“现有方法效果不好”，而是解释：

> **现有方法为什么无法从根本上解决这个问题？**

### 3. 你的方法为什么可行？

在提出新方法后，需要建立清晰的因果逻辑，说明：

* 你的方法针对的是哪一个关键原因；
* 你的设计如何弥补现有方法的不足；
* 为什么这种设计能够解决前面提出的问题；
* 最终结果如何证明你的判断成立。

核心需要回答的是：

> **为什么你的方法能够比现有方法更有效地解决这个问题？**
